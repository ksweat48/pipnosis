## Troubleshooting

### Issue: Chart Still Shows Old Data

**Solution**: Hard refresh browser (Ctrl+Shift+R)

### Issue: Some Candles Missing

**Possible Causes**:
- Market was closed (weekends, holidays)
- Yahoo Finance API hiccup (rare)

**Solution**: Re-run backfill script for specific symbol/timeframe

### Issue: Gaps in Historical Data

**Note**: Gaps during weekends/market closure are **expected and correct**
- Forex markets close Friday 5pm EST to Sunday 5pm EST
- This is not a bug - no trading occurred during these periods
